01 // Commercial Systems & Engineering Case Studies

Real-Time Fleet Telemetry & Map Marker Interpolator // Slash Plus

1,500+ Active Vehicles Sub-3s Coordinate Batching Worker Isolate Pool Ticker Bearing Interpolation

Live tracking engine monitoring 1,500+ commercial vehicles across nationwide transit routes in Nepal.

Problem & Constraints: High-frequency Socket.IO telemetry packets arrived so rapidly that deserializing JSON payloads on Flutter's main UI thread saturated the isolate event loop, triggering frame drops and halting map animations.

Solution & Architecture: Offloaded payload deserialization and validation to a dedicated, persistent worker isolate pool. Coordinates are batched into 3-second temporal windows and smoothly interpolated using custom ticker-driven spherical bearing and position interpolation curves.

Extracted Open Source Packages: animated_marker, isolate_runner_mixin

Offline-First Transit Media & Signage Player // Slash Plus

100+ Transit Displays Sub-200ms Transitions SQLite Priority Queue 150ms RSA Verification

Autonomous digital signage and infotainment systems operating on commercial passenger transit buses.

Problem & Constraints: Harsh onboard vehicular operating environments characterized by abrupt engine power cuts, frequent cellular dead zones along mountain highways, and severe thermal throttling on low-cost Android hardware.

Solution & Architecture: Implemented a resilient offline-first SQLite state machine with durable priority task queues, cryptographic lease verification, and atomic file swaps. Integrated native C/Android cryptographic acceleration, slashing cryptographic verification latency from 15 seconds to 150 milliseconds.

Extracted Open Source Packages: resumable_downloader, ffr_crypto

Handheld Android POS Fleet & Direct Thermal Printer Engine // Slash Plus

30+ Field Devices Sub-10ms Ticket Renders Raw ESC/POS Streaming Hardware Fault Recovery

Fleet of handheld Android POS devices deployed for physical ticketing across transit terminals.

Problem & Constraints: Vendor Android printer SDKs suffered from unmanaged memory leaks, thread contention, and unpredictable printer freezes during peak ticketing rushes.

Solution & Architecture: Engineered a direct binary ESC/POS byte streaming pipeline over low-level Android hardware interfaces, bypassing vendor runtime layers. Rendered print layouts on an offscreen Flutter Canvas at sub-10ms latency with cryptographically signed local transaction ledgers.
